# Birdie website

Website, guide, and draft language specification for [Birdie](https://github.com/birdie-lang/birdie).

[birdie.jakmaz.com](https://birdie.jakmaz.com)

## Development

Built with Astro and Bun.

```sh
bun install
bun run dev
```

Check types with `bun run typecheck`.

## Content

- `src/content/docs/`: guide, specification, and project notes.
- `src/data/examples/`: examples displayed on the website.
